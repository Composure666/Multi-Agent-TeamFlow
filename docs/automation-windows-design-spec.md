## 0. 共同基础（三个窗口共享）

### 0.1 功能定位

| 窗口 | 定位 | 实现载体 | 触发入口 |
|---|---|---|---|
| 新建自动化 | 从零描述一个自动化任务：它做什么、在哪执行、多久跑一次 | `Dialog`（`dialogMode === 'create'`） | 标题栏右上「添加」按钮 |
| 编辑自动化 | 修改已有任务的配置；字段与新建完全一致，仅初值与提交分支不同 | **同一个 `Dialog`**（`dialogMode === 'edit'`） | 详情面板「编辑」按钮（须先选中任务） |
| 自动化详情 | 查看单个任务的配置快照、运行状态，并执行编辑 / 暂停 / 运行 / 删除 | 工作区内嵌选中态面板（非独立路由/Dialog） | 点击任务卡片 |

**圆角**

| 元素 | 半径 |
|---|---|
| Dialog 容器 | 16px |
| 详情面板 | 20px |
| 输入框 / 小卡 / 提示条 | 8–12px |
| 任务图标容器 | 16px |
| 按钮 / chip / 徽章 / 圆形图标钮 | 9999px（全 pill） |

**阴影**

- Dialog：`0 24px 56px -8px rgba(10,13,15,.18)` + `0 2px 8px rgba(10,13,15,.10)`
- 详情面板：`0 16px 36px -4px rgba(0,100,224,.12)`

**排版**（Inter）

| 角色 | 字号 / 字重 |
|---|---|
| 窗口标题 | 22 / 700 |
| 分区标题 | 14 / 700 |
| 字段标签 | 13 / 600 |
| 正文 / 输入值 | 14 / 400–600 |
| 说明 / meta | 12 / 400–500 |
| 徽章 / chip | 11–12 / 700 |

**间距**：基础单位 4px；区块纵向 24px；字段行 16px；标签与控件 6px；Dialog 左右内边距 28px。

**图标**：全部为 SVG 矢量节点，禁止 emoji / 字体图标 / 单字母假图标；线性图标统一 2px 描边、圆角端点。

### 0.3 交互一致性

- **关闭**：遮罩点击、`Esc`、右上 `X`、底部「取消」四条路径等价，均清空 `dialogMode`（详情面板为 `setSelectedTaskId(null)`）。
- **提交中锁定**：`submitting || promptFilling` 期间，「取消 / 保存」均禁用，主按钮文案切换为「保存中…」。
- **焦点态**：输入框获得焦点时描边切换为 2px `#0064E0` + 浅蓝底，错误态切换为 `#F0284A`（配下方红色说明行）。
- **键盘**：`⌘/Ctrl + Enter` 提交（底部左侧常驻提示）。

## 1. 新建自动化窗口

### 1.1 区域划分（自上而下）

```
┌ Dialog Header ─────────────────────────────────────┐
│ [新建 / Create] 徽章                                   [X] │
│ 创建自动化任务                                           │
│ 配置任务提示词、执行目标和基础触发计划。                      │
├────────────────────────────────────────────────────┤
│ ① 基本信息   （2 列网格 + 1 单列）                        │
│    标题* / 分类      ← 一行两列                           │
│    描述              ← 整行                              │
│ ② 任务提示词 （textarea + 右上 AI 优化）                   │
│    计数 0/800 · [✦ AI 优化]                              │
│    ┌ 多行文本域（min-h 128 / max-h 256）┐                 │
│ ③ 执行目标   （2 列）                                    │
│    目标 Agent / 目标会话                                 │
│ ④ 触发计划   （预览句 + 3 列）                            │
│    预览：手动触发，由用户主动立即运行。                      │
│    触发类型 / 间隔分钟 / 状态                             │
│    ▸ 条件字段说明行（规则表达）                            │
│ ⑤ 提示条（黄）保存后的行为说明                             │
├ Footer ────────────────────────────────────────────┤
│ [⌘/Ctrl + Enter 保存]            [取消] [✓ 保存草稿]      │
└────────────────────────────────────────────────────┘
```

### 1.2 字段构成与分组

| 分组 | 字段 | 控件 | 默认值 | 校验 |
|---|---|---|---|---|
| 基本信息 | 标题 `title` | Input（文本） | 空 | **必填**，空则顶部红色错误条 |
| | 分类 `category` | Input（下拉态） | `自定义任务` | 自由文本标签 |
| | 描述 `description` | Input（整行） | 空 | 选填 |
| 任务提示词 | 提示词 `prompt` | Textarea | 空 | **必填**；右上 `✦ AI 优化` 打开 `PromptEnhanceModal` |
| 执行目标 | 目标 Agent `agentId` | Select | `Auto · 自动指派`（空值） | 选填，空则系统指派 |
| | 目标会话 `conversationId` | Select | `未绑定会话`（空值） | 选填 |
| 触发计划 | 触发类型 `scheduleType` | Select | `手动触发 · Manual` | 决定下方条件字段显隐 |
| | 间隔分钟 `intervalMinutes` | Number | `60` | 仅 `interval` 展示 |
| | 时间 `timeOfDay` | Time | `09:00` | 仅 `daily` / `weekly` 展示 |
| | 星期 `dayOfWeek` | Select | `1`（周一） | 仅 `weekly` 展示 |
| | 状态 `status` | Select | `草稿 / Draft` | 仅 `draft / enabled / paused`，**不含 `running`** |

> 触发类型与条件字段的显隐规则（设计稿已用说明行表达）：
> `interval → 间隔分钟`；`daily → 时间`；`weekly → 时间 + 星期`；`manual → 无附加字段`。

### 1.3 按钮与交互

| 按钮 | 行为 | 禁用条件 |
|---|---|---|
| 取消 | 清空 `dialogMode` 关闭弹窗 | `submitting \|\| promptFilling` |
| 保存草稿（主） | `handleSaveAutomation()` → 校验 → `buildAutomationSaveBody(form)` → `createAutomation(body)` | 同上；提交中文案变「保存中…」 |
| ✦ AI 优化 | 拼接入参 → `optimizePrompt` → 打开对比弹窗，可选「使用原版 / 使用优化版」回填 `form.prompt` | 同上；进行中文案变「AI 优化中」 |

保存成功 → 关闭弹窗、`setSelectedTaskId(saved.id)`（自动跳详情）、推送 `success` 通知、`loadDashboard()` + `refreshConversations()`。

## 2. 编辑自动化窗口

### 2.1 与新建的关系

**同一份 `Dialog` 组件**，仅三处差异：

| 维度 | 新建 | 编辑 |
|---|---|---|
| 徽章文案 | `新建 / Create` | `编辑 / Edit` |
| 标题 | 创建自动化任务 | 编辑自动化任务 |
| 表单初始化 | `automationFormFromTask()`（空 + 默认） | `automationFormFromTask(selectedTask)`（快照预填） |
| 提交接口 | `POST /api/automations` | `PATCH /api/automations/:id` |
| 成功通知 | 自动化任务已创建 | 自动化任务已更新 |
| 成功副作用 | 选中新任务、详情展开 | 保留选中态、详情继续展开 |

### 2.2 字段组织

与新建**完全一致**（同样的分组、同样的 2 列 / 3 列网格、同样的条件显隐），仅初始值不同。编辑态下额外表达：

- 标题 / 分类 / 描述 / 提示词 显示已有值（正文色 `#1C1E21`）；
- 字符计数切换为真实值（示例 `146 / 800`）；
- 触发计划展示当前配置（示例：每周一 09:00 / Weekly + 状态「启用 / Enabled」，绿色语义）；
- 分区标题右侧提示语由「必填 · 1 项」改为上下文信息；
- 底部提示条配色由**黄色（提示）切换为蓝色（信息）**，文案说明「编辑后仍属于同一任务，详情面板会保留选中态并刷新元信息」；
- 主按钮文案「保存更新」，按钮内文案与图标同步（对勾 → 更替为更新语义）。

## 3. 自动化详情面板

### 3.1 区域划分

```
┌ 顶部 accent 描边条（6px，Cobalt）────────────────────┐
├ Header ──────────────────────────────────────────┤
│ [icon]  [选中任务/Selected] [市场调研/Market Research]    [X] │
│         定时同步竞品文档                                   │
│         ● 运行中 · Running   当前正在执行一次手动触发的运行…    │
├ Meta 4 列 ────────────────────────────────────────┤
│  分类 / Category │ 触发节奏 / Cadence │ 下次运行 │ 最近运行    │
│  市场调研         │ 每周一 09:00      │ 周一 11/17│ 今日 14:28 │
│  用户自定义标签    │ Weekly·Asia/Shanghai│ 距下次2天18h│ 成功12s·12.4s│
├ 任务提示词预览 ────────────────────────────────────┤
│  [只读 · line-clamp 3]                                  │
│  ┌ 提示词正文（最多 3 行 + 「+ N 行内容已折叠」）┐          │
│  ┌ 最近错误块（红）：错误时间 + 错误详情 ┐                  │
├ 操作按钮组 ────────────────────────────────────────┤
│  [✎ 编辑] [⏸ 暂停] [▶ 立即运行] [🗑 删除]    [复制] [⋯]     │
├ 运行历史 ─────────────────────────────────────────┤
│  运行历史  [前 4 条 / 共 18 条]              查看全部 →     │
│  ┌ 每行：状态色块图标 + 「最新」chip + 触发方式·状态 + 相对时间 │
│  │        下文：执行摘要 / 错误信息（失败时红色）            │
│  └ 空态：「暂无运行历史」dashed 卡                          │
└──────────────────────────────────────────────────┘
```

### 3.2 展示信息

| 分区 | 元素 | 数据来源 |
|---|---|---|
| 标题行 | 任务标题（h2 22/700） | `task.title` |
| | 分类 chip（浅蓝） | `task.category` |
| | 「选中任务 / Selected」状态 chip（实心 Cobalt） | 选中态标识 |
| | 状态徽章 + 状态描述 | `automationStatusLabel` / `automationStatusDescription(rawStatus)` |
| Meta 4 列 | 分类 / 触发节奏 / 下次运行 / 最近运行 | `task.category` / `task.cadence` / `formatDateTime(nextRunAt)` / 相对时间（`今日 HH:mm` / `昨日 HH:mm` / `N 天前` / `MM-DD` / `尚未运行`） |
| 提示词预览 | 正文（line-clamp 3）+ 折叠提示 | `task.prompt`，空时「暂无提示词」 |
| 最近错误 | 错误时间 + 错误详情（红） | `task.lastError`（存在时才渲染） |
| 运行历史 | 每行：触发方式（手动/计划）+ 状态（成功/运行中/失败）+ 相对时间 + 首条日志 | `fetchAutomationRuns(selectedTaskId)`，默认前 4 条 |

### 3.3 可执行操作

| 按钮 | 层级 | 调用 | 成功副作用 | 进行中文案 |
|---|---|---|---|---|
| 编辑 | 一级（黑色 outline pill） | `openEditDialog()` | 打开编辑弹窗、表单预填 | — |
| 暂停 / 启用 | 一级（琥珀 / 绿色） | `disableAutomation` / `enableAutomation` | 重拉 dashboard（启用额外刷新会话） | 暂停中… / 启用中… |
| 立即运行 | 一级（Cobalt 实心，主操作） | `runAutomationNow(id)` | 重拉 dashboard + 通知「已提交自动化运行」 | 提交中… |
| 删除 | 一级（红色 outline） | `window.confirm` → `deleteAutomation(id)` | 清空选中态、重拉 dashboard | 删除中… |
| 复制 / 更多 | 三级（圆形图标钮，右对齐） | 预留 | — | — |

`actionLoading` 保证同一时刻仅一个动作在飞，其余按钮置灰。

## 4. 跳转与关联

```
自动化工作区
  ├─ 点击「添加」 ─────────────→ 新建自动化 Dialog ──保存成功──→ 详情面板（新任务自动选中）
  ├─ 点击任务卡片 ────────────→ 详情面板（再次点击同一卡片收起）
  │      └─ 点击「编辑」 ──────→ 编辑自动化 Dialog ──保存成功──→ 详情面板（保留选中态）
  │      └─ 点击「删除」 ──────→ 确认后 → 详情面板消失、回到全量卡片视图
  └─ 新建/编辑弹窗内 ──「✦ AI 优化」──→ PromptEnhanceModal（旁路；详情中无此入口）
```

**共享元素**：状态徽章配色与文案三处复用；`AutomationTaskPreset` 视图模型同时供卡片网格与详情面板使用；「✦ AI 优化」仅存在于新建 / 编辑窗口。

## 5. 开发落地要点

1. **一个 Dialog，两种模式**：新建与编辑严禁拆成两个组件，避免字段漂移；差异集中在标题文案、表单初始化与提交分支。
2. **条件字段用同一份规则表驱动**：由 `scheduleType` 决定渲染哪些附加字段，UI 与 `buildAutomationSaveBody` 的序列化分支必须一一对应。
3. **`status` 选项排除 `running`**：类型层面已约束为 `Exclude<AutomationStatus, 'running'>`，UI 不得暴露该项。
4. **详情面板的 `nextRunAt` 可为空**：需渲染「—」而非空白，并保留「尚未计算」的语义。
5. **删除必须二次确认**：沿用 `window.confirm`（或替换为同视觉规范的确认弹窗，但需保持文案一致）。
6. **无障碍**：关闭按钮带 `aria-label="关闭自动化详情"`；状态不只靠颜色区分，需同时给出文字标签（成功/失败/运行中）。
